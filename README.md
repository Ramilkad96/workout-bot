# Бот для учёта тренировок — деплой на Railway

## 1. Получить токен бота
1. В Телеграме открыть **@BotFather** → `/newbot` → задать имя и username.
2. BotFather пришлёт токен вида `123456:AA...` — это `BOT_TOKEN`.

## 2. Завести аккаунт на Railway
1. https://railway.app → Sign up (можно через GitHub).
2. Railway даёт бесплатный пробный баланс — этого достаточно, чтобы бот
   крутился постоянно; когда закончится, попросит привязать карту для
   дешёвого посуточного тарифа.

## 3. Выложить код
Проще всего — через GitHub:
1. Создать пустой репозиторий на github.com, например `workout-bot`.
2. Загрузить в него файлы из этой папки: `bot.py`, `requirements.txt`,
   `Procfile` (файл `.env.example` не обязателен, `sync_to_excel.py` тоже
   не нужен на сервере — он выполняется отдельно).
3. В Railway: **New Project → Deploy from GitHub repo** → выбрать
   `workout-bot`.

## 4. Переменные окружения
В Railway: Project → Variables → добавить:
- `BOT_TOKEN` — токен от BotFather
- `EXPORT_TOKEN` — придумать длинную случайную строку (например,
  сгенерировать: `python3 -c "import secrets; print(secrets.token_hex(24))"`)
- `DB_PATH` — `/data/workouts.db`

## 5. Постоянное хранилище (volume)
Без этого база данных будет стираться при каждом передеплое.
В Railway: Project → Settings → Volumes → **New Volume** → mount path `/data`.

## 6. Публичный адрес
Railway → Settings → Networking → **Generate Domain**. Получится адрес
вида `https://workout-bot-production.up.railway.app` — он понадобится для
синхронизации с таблицей.

## 7. Проверка
После деплоя открыть бота в Телеграме и отправить `/start` — должна
появиться клавиатура выбора дня.

## Как данные попадают в xlsx
Бот сам НЕ трогает файл на твоём компьютере — он только копит записи в
своей базе в облаке. Чтобы перенести их в
«Дневник тренировок.xlsx» на Рабочем столе, просто напиши в этом чате
что-то вроде «обнови таблицу тренировок» — Клод запросит данные с бота
(`/export`) и пересоберёт файл с сохранением уже введённых тренировок,
просто дописывая новые тренировки правыми колонками.

Если хочешь, чтобы это происходило само — можно попросить Клода настроить
периодическую задачу (например, раз в день), которая будет делать это
автоматически.
